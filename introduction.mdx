Orvlin handles usage-based, seat-based, prepaid, and hybrid billing for SaaS and AI products. Your application sends usage events, and Orvlin turns them into prices, entitlements, invoices, and payments.

<Tip>
New here? Start with the [Quickstart](/quickstart) for a working setup in a few minutes, or the [Integration guide](/guides/integrate-your-app) for a step-by-step path into your app. A sandbox workspace is included, so you can test without moving real money.
</Tip>

## Key features

- **Usage metering:** send events with idempotency keys, so retries never count twice. Metrics count, sum, take the max, count distinct values, or run custom SQL. See [Usage metering](/guides/usage-metering).
- **Entitlements:** check what a customer can use before the work runs. Answers are cached locally, so checks stay fast. See [Entitlements](/guides/entitlements).
- **Prepaid credits:** grant credits, sell packs, and top up automatically when a balance runs low. See [Prepaid credits](/guides/prepaid-credits).
- **Invoicing and collection:** issue, approve, void, and credit invoices. Failed charges are retried on a schedule. See [Invoicing and collection](/guides/invoicing-and-collection).
- **Customer portal:** let customers see usage and invoices, and change plans, inside your own app. See [Customer portal](/guides/customer-portal).
- **Signed webhooks:** get notified about invoices, subscriptions, and approvals, with signatures you can verify. See [Webhooks](/api-reference/webhooks).
- **Integrations:** sync with tax engines, CRMs, accounting tools, data warehouses, and cloud marketplaces. See [Integrations](/guides/integrations).
- **Sandbox and test clocks:** test renewals, invoices, and payment retries in minutes. See [Test billing](/tutorials/test-billing-with-test-clocks).
