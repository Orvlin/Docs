This page is for people working on Orvlin itself. To use Orvlin in your product, start with the [Quickstart](/quickstart).

## Prerequisites

- **Node.js** 22.13 or later
- **pnpm** 11.1.1 (set by the `packageManager` field)

## Install and build

```bash
git clone https://github.com/mehedihnb/orvlin.git
cd orvlin
pnpm install
pnpm run build
```

## Run the stack

Start the API and dashboard in development mode:

```bash
pnpm run dev
```

The API listens on `http://localhost:3000`. Routes are served under `/v1`. The health check is `GET /v1/health`.

For the dashboard alone, proxied to the API on port 3000:

```bash
pnpm --filter @orvlin/web dev
```

## Monorepo layout

| Path | Contents |
|---|---|
| `packages/api` | Fastify API server. |
| `packages/core` | Revenue engine: event store, ingestion, query, simulation. |
| `packages/cli` | The `orvlin` command-line tool. |
| `packages/sdk-node`, `packages/sdk-python`, `packages/react` | Client SDKs. |
| `packages/web` | Dashboard (React and Vite). |
| `packages/shared` | Shared types and schemas. |

## Tests and checks

```bash
pnpm run test        # package tests
pnpm run typecheck   # TypeScript checks
pnpm run lint        # lint all packages
```

See [Testing](/testing) for the sandbox and test-clock features you can use to test billing behaviour.

## Documentation

These docs are a [Mintlify](https://mintlify.com) project in the `docs/` folder. To preview them locally:

```bash
npm i -g mintlify
cd docs
mintlify dev
```

The preview runs at `http://localhost:3000`.
